# מאמן קול (VoiceTrainer) 🎤🧠

אפליקציית אנדרואיד נייטיבית (Kotlin) שמאמנת **רשת נוירונים על המכשיר** לזהות את הקול שלך — בלי שרת, בלי ספריות ML חיצוניות. כל הקוד ממומש מאפס:

- **חילוץ פיצ'רים** (`dsp/Mfcc.kt`) — חלון Hamming, FFT radix-2, בנק מסנני Mel, DCT → 13 מקדמי MFCC לכל פריים של 25ms.
- **רשת נוירונים** (`nn/NeuralNetwork.kt`) — MLP בגודל 13→24→16→1 עם ReLU ו-sigmoid, אימון עם backpropagation מלא ו-Adam optimizer, פונקציית הפסד binary cross-entropy.
- **נתונים ומודל** נשמרים באחסון הפנימי של המכשיר בלבד — שום דבר לא עוזב את הטלפון.

## איך משתמשים

1. **🎤 הקלט את הקול שלי** — הקלט כ-5–10 קליפים של 3 שניות שבהם אתה מדבר (משפטים שונים, מרחקים שונים מהמיקרופון).
2. **🔊 הקלט רעש / קול אחר** — הקלט כ-5–10 קליפים של רעש רקע, שקט, טלוויזיה, או אנשים אחרים מדברים.
3. **🧠 אמן את הרשת** — האימון רץ על המכשיר (כ-40 אפוקים, שניות בודדות) ומציג את ה-loss בזמן אמת.
4. **▶️ זיהוי חי** — האפליקציה מאזינה ברציפות ומציגה בכל חצי שנייה את ההסתברות שהקול הנשמע הוא שלך.

ככל שמקליטים יותר דוגמאות מגוונות — הזיהוי משתפר. אפשר להוסיף הקלטות ולאמן שוב בכל שלב.

## בנייה

```bash
cd android
./gradlew assembleDebug
# APK ייווצר ב: app/build/outputs/apk/debug/app-debug.apk
```

דרישות: JDK 17+, Android SDK עם platform 34. התקנה על המכשיר: `adb install app/build/outputs/apk/debug/app-debug.apk` (או העברת ה-APK לטלפון והתקנה ידנית).

## איך זה עובד מבפנים

כל קליפ מפורק לפריימים של 25ms (חפיפה של 10ms). מכל פריים מחולץ וקטור של 13 מקדמי MFCC — ייצוג קומפקטי של גוון הקול (timbre). בקליפים של "הקול שלי" נשמרים רק פריימים שבהם באמת יש דיבור (סינון לפי RMS), כדי ששקט לא יתויג בטעות כקול שלך. הרשת מאומנת לסווג כל פריים בנפרד (תווית 1 = אתה, 0 = אחר), ובזיהוי החי ההסתברות היא ממוצע הפרדיקציות על הפריימים הקוליים בשנייה האחרונה. הקלט מנורמל לפי ממוצע וסטיית תקן של סט האימון, שנשמרים יחד עם המשקולות.
